# 営業サポートサイト

スケジュール・名刺・訪問ルート・出張手配(ホテル/レンタカー)・資料・営業日報・団体打ち合わせ表を
ひとつの画面で管理する、インストール不要の営業支援サイトです。

## まずはここから: 共有版(チーム全員で同じデータ)
**https://eigyo-support-633yw2zkkq-an.a.run.app/**

- 開くと「ログイン名とパスワード」の画面が出ます。一人ひとりにアカウントがあります。
- **はじめて使うとき(最初の1回だけ)**: 「はじめての設定」画面で最初の管理者を作成します。このとき「初期設定コード」が必要です。コードの確認(Macのターミナルで):
  ```bash
  gcloud secrets versions access latest --secret=EIGYO_SITE_PASSWORD --project=sansuiso-apps
  ```
- **メンバーの追加**: 管理者が「設定 → アカウント → メンバー管理」でログイン名・表示名・初期パスワードを登録し、本人に伝えます。本人は設定画面でパスワードを変更できます。管理者はパスワードの再設定・削除もできます。
- ログインは30日間ブラウザが覚えます。「設定 → アカウント → ログアウト」で切れます。
- スマホは「ホーム画面に追加」しておくとアプリのように使えます。
- データは全員で共有され、Google Cloud(プロジェクト sansuiso-apps、バケット sansuiso-eigyo-data)に保存されます。
- 写真の読み取り・AIへの注文・住所のAI検索は、この共有版でだけ動きます。

## 使い方(そのほかの開き方)
共有版を使わずに手元だけで動かす方法です。

| 開き方 | データの場所 | スマホとPCで同じデータ |
|---|---|---|
| A. `index.html` をダブルクリック | そのブラウザの中だけ | ✕(JSONの書き出し/取り込みで手動コピー) |
| B. Macで `起動.command` をダブルクリック(推奨) | Macの `data/` フォルダ | ○ 同じWi-FiのiPhone/PCから同じデータ |
| C. `python3 -m http.server` などの簡易サーバー | そのブラウザの中だけ | ✕ |

### A. いちばん簡単な方法(1台だけで使う)
`index.html` をダブルクリックしてブラウザで開くだけで動きます(地図やOCRなど一部機能はインターネット接続が必要)。

### B. スマホとPCで同じデータを使う(推奨)
Mac で小さな「同期サーバー」を動かしておくと、同じWi-Fiにつながった iPhone / iPad / 別のPC から
同じデータを見たり編集したりできます。データは Mac のこのフォルダ内の `data/` に保存されます(インターネットには出ません)。

**1. 準備(最初の1回だけ)** — Node.js を入れる
1. https://nodejs.org/ を開き、「LTS」と書かれたボタンから Mac 用インストーラーをダウンロードして実行します(すべて「続ける」でOK)。
2. 入ったか確認したい場合は「ターミナル」で `node -v` と打つと `v20.x` のように表示されます。

**2. サーバーを起動する(使うたび)**
1. このフォルダの `起動.command` をダブルクリックします(黒い画面が開き、次のように表示されます)。
   ```
   営業サポート サーバーを起動しました。止めるときは Ctrl+C
     このMacで開く:          http://localhost:8765
     同じWi-Fiのスマホから:  http://192.168.1.23:8765
   ```
   - 初回に「開発元を確認できないため開けません」と出たら、`起動.command` を **右クリック → 開く** を選び、もう一度「開く」を押してください(2回目からはダブルクリックで開きます)。
   - 「ターミナル」から起動する場合は次のコマンドでも同じです。
     ```bash
     cd "/Users/key/Documents/ClaudeCode/営業" && node server.js
     ```
2. Mac のブラウザで `http://localhost:8765` を開きます。
3. **iPhone** の Safari で、黒い画面に表示された「同じWi-Fiのスマホから」のアドレス(例: `http://192.168.1.23:8765`)をそのまま入力して開きます。
   - 共有 → 「ホーム画面に追加」をしておくと、次からアプリのように開けます。
   - アドレスは Wi-Fi 環境が変わると変わることがあります。黒い画面に出ている最新のものを使ってください。
4. 設定画面の「スマホ・PC間の同期」が **接続中** になっていれば完了です。どちらで保存しても、もう片方は画面に戻ったとき/再読み込みで同じ内容になります(自動でも約30秒ごとに取り込みます)。「🔄 今すぐ同期」ですぐに取り込めます。

**3. 止める** — 黒い画面で `Ctrl` + `C` を押すか、ウィンドウを閉じます。止めている間も各端末は端末内のデータで今までどおり使え、次にサーバーを動かして開いたときに未送信の変更を自動で送ります。

**うまくつながらないとき**
- iPhone と Mac が **同じWi-Fi** につながっているか確認(iPhoneのモバイル通信ではつながりません)。
- Mac の「システム設定 → ネットワーク → ファイアウォール」が有効な場合、初回起動時の「接続を許可しますか?」で **許可** を選びます。
- Mac がスリープしているとつながりません。使う間はスリープしないようにしてください。
- 「ポート 8765 はすでに使われています」と出たら、ターミナルで `node server.js 8766` のように別の番号で起動し、アドレスの番号も合わせます。
- 設定画面の同期状態が「オフライン」でも、入力したデータは端末内に残っています。サーバーにつながった時点で自動的に送られます。

**同時に編集したら?** 別々の件(別の顧客、別の予定など)を直した分は両方残ります。**同じ1件** をスマホとPCで同時に直した場合は、後にサーバーへ送られた方が残ります(簡易方式のため)。

**ログイン(パスワード)をかける** — 外出先のWi-Fiなど、同じネットワークに知らない人がいる場所で使うときは、ログインを設定して起動してください。設定しないと、同じWi-Fiにいる人は誰でもデータを見られます。
```bash
cd "/Users/key/Documents/ClaudeCode/営業" && AUTH_REQUIRED=1 node server.js
```
開くとログインの入力画面が出ます。一度入れると30日間は聞かれません。設定画面の「ログアウト」で解除できます。

### C. ローカルサーバーで開く(同期なし)
```bash
cd "/Users/key/Documents/ClaudeCode/営業" && python3 -m http.server 8765
```
その後ブラウザで http://localhost:8765 を開きます。スマホからも開けますが、データは端末ごとに別々です(設定画面の同期状態は「端末内のみ」になります。同じデータにするには B を使ってください)。

## 最初にやること
1. 「設定」で氏名・会社名・**拠点(出発地)の住所**を登録(ルート作成の出発地になります)
2. 「顧客・名刺」で訪問先を登録(名刺写真の保存・OCR読み取りも可)
3. 「スケジュール」に訪問予定を入れる → 「ルート作成」で最適な回り方を提案 → 「営業日報」は予定から自動下書き

## 名刺をまとめて取り込む
「顧客・名刺」画面の「📇 名刺をまとめて取り込む」で、名刺の写真を複数枚選ぶ(スマホなら「撮影して追加」で続けて撮る)と、AIが1枚ずつ会社名・氏名・役職・電話・メール・住所などを読み取ります。内容を確認・修正して「選択を登録」を押すと、名刺画像付きで顧客に登録されます(同じ会社・氏名が登録済みなら上書き更新)。住所の座標は登録後に自動で取得します。この機能は共有版(クラウド版)でのみ動きます。

## 営業計画(複数日の訪問計画を一気に作る)
「営業計画」ページで、次の流れで期間全体の営業予定と毎日のルートを作れます。
1. **訪問先リストを取り込む** … 名簿の写真・PDF(AIが表を読み取り)、Excel/CSV、または登録済みの名刺から選ぶ
2. **絞り込む** … 区分(旅行会社 / 法人 / 自治体 など)のチップで「旅行会社だけ回る」のように選択
3. **希望を入れる** … 表の「希望日」「時間帯」に直接入れるか、「AIに注文」欄に日本語で書く(例:「A社は2日目の午前、B社は最終日の15時以降」「メディアは回らない」)
4. **住所が無い行** … 「AIで住所を調べる」でWeb検索から所在地を入れる(必ず内容を確認)。「座標を取得」で地図上の位置を確定
5. **計画を自動作成** … 近い順に日ごとへ振り分け、各日の順番を最適化。到着・出発時刻つきの行程と距離が出る。↑↓や「移す…」で手直し可
6. **予定表に反映** … 各日の訪問を「スケジュール」に登録し、日ごとのルートも保存。「ルート作成」画面で地図やGoogleマップ連携が使える

写真の読み取り・AI注文・住所検索はクラウド版(Cloud Run)でのみ動きます。パスポート番号や生年月日などは読み取りません。

## データの保存場所
- データはまず各端末のブラウザの中(localStorage / IndexedDB)に保存されます。共有版では Google Cloud に保存します。営業計画の「写真の読み取り」「AIに注文」「AIで住所を調べる」は、その写真・PDF・会社名などを Google の Gemini API に送って処理します(パスポート番号などは読み取らない指示にしています)。
- B の方法で起動している間は、保存のたびに Mac の `data/` フォルダにも書き込まれます(`data/data.json` が設定と各データ、`data/files/` が添付・名刺画像)。このフォルダをコピーすればバックアップになります。
- 別端末へ手動で移す・バックアップを取るときは「設定 → JSONを書き出す/取り込む」も使えます(添付ファイルは含まれません)。
- ブラウザの履歴・サイトデータを消すと端末内のデータは消えます。B を使っていれば次に開いたとき Mac から復元されますが、A だけで使っている場合は定期的に書き出しておくことを推奨します。

## できないこと
- ホテル・レンタカーの**実際の予約**は各予約サイトで行います。本サイトは条件付きで各サイトを開き、予約結果(確認番号など)を記録します。
- 地図・住所検索・経路計算は無料の公開サービス(OpenStreetMap / Nominatim / OSRM)を使っているため、混雑時は失敗することがあります。その場合は直線距離からの推定値を表示します。

## 構成
- `index.html` … 画面の枠。`css/app.css` … 見た目
- `server.js` … 同期サーバー(Node.js、依存パッケージなし)。`起動.command` … それをダブルクリックで起動するもの
- `data/` … サーバー起動時に作られる保存先(data.json, files.json, files/)
- `js/store.js` 保存、`js/ui.js` 画面部品、`js/geo.js` 地図/経路、`js/app.js` 画面切替
- `js/pages/*.js` … 各機能ページ
- `DESIGN.md` … 設計書(データ構造など)
